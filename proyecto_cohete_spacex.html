Modelo Matematico

Sistema de EDOs del cohete:

El movimiento vertical de un cohete se modela con el siguiente sistema de ecuaciones diferenciales ordinarias:

dy/dt = v    (1) posicion
dv/dt = (T - D - mg) / m   (2) velocidad
dm/dt = -q    (3) masa

donde:
T = empuje del motor (N)
D = 0.5 * rho(y) * v^2 * Cd * A  (arrastre)
rho(y) = 1.225 * exp(-y/8500)  (densidad aire)
g = 9.81 * (R_tierra / (R_tierra + y))^2
q = tasa de consumo de combustible (kg/s)
Condiciones iniciales: y(0)=0, v(0)=0, m(0)=m_seco + m_fuel

Fases del vuelo:
1. Ascenso con motor: T > 0, combustible se consume
2. Ascenso balistico: T = 0, solo gravedad y arrastre
3. Descenso: v < 0, caida libre
4. Frenado retropropulsivo: T reactivado para aterrizar

Metodos Numericos Aplicados

1. Runge-Kutta 4 (RK4) - Clase 7
Integra el sistema de EDOs con precision O(h^4). Es el metodo principal de la simulacion.

2. Euler y Euler Modificado (Heun) - Clase 7
Comparados con RK4 para demostrar la importancia del orden del metodo.

3. Monte Carlo - Clase 6
Estimacion probabilistica del exito de la mision con incertidumbres en parametros.

4. Biseccion - Clase 1
Encuentra el combustible minimo para alcanzar la altitud objetivo.

5. Newton-Raphson - Clase 2
Optimizacion mas rapida del combustible con convergencia cuadratica.

6. Derivacion Numerica - Clase 3
Calculo de aceleracion a partir de datos de velocidad.

7. Integracion Numerica (Simpson) - Clase 5
Calculo del impulso total y trabajo realizado por el motor.
